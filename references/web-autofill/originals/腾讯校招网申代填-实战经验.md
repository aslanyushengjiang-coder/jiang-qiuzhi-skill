## 四、核心方法：五类控件怎么填

### 4.1 文本输入框 —— 必须用 execCommand

**❌ 错误做法**（本次踩过的坑）：
```js
el.value = '余生姜';
el.dispatchEvent(new Event('input', { bubbles: true }));
```
DOM 层当时能读到值，但 Element Plus 是受控组件，**组件一重渲染就被回滚清空**。实测：连填 16 个文本框后做了几轮下拉交互，再回读全部为空。

**✅ 正确做法**：
```js
var el = document.querySelector('input[placeholder="请输入姓名"]');
el.focus();
// 重新查询一次，避免 Vue 重渲染替换节点后引用失效
var again = document.querySelector('input[placeholder="请输入姓名"]');
if (again) again.focus();
document.execCommand('selectAll', false, null);
document.execCommand('insertText', false, '余生姜');
```

`execCommand('insertText')` 触发的是**浏览器原生输入事件**，Vue 认，且 `selectAll` 保证替换已有值。

**textarea 同理**，不要用赋值。

### 4.2 单选 el-radio —— 直接 click label

```js
document.querySelectorAll('label.el-radio').forEach(function (l) {
  if (l.innerText.trim() === '男') l.click();
});
```

回读判断：选中的 label 会带 `is-checked` 类。

DOM 结构：
```html
<label role="radio" class="el-radio">
  <span class="el-radio__input"><span class="el-radio__inner"></span>
    <input type="radio" aria-hidden="true" tabindex="-1" class="el-radio__original" value="男">
  </span>
  <span class="el-radio__label">男</span>
</label>
```

### 4.3 下拉 el-select —— 三段式

DOM 结构：
```html
<div class="el-select">
  <div class="el-input el-input--suffix">
    <input type="text" readonly="readonly" placeholder="请选择您的国家/地区" class="el-input__inner">
    <span class="el-input__suffix"><i class="el-select__caret el-icon-arrow-up"></i></span>
  </div>
</div>
```

**步骤**：
```js
// ① 派发三种鼠标事件（缺一可能不展开）
['mousedown', 'mouseup', 'click'].forEach(function (ev) {
  inp.dispatchEvent(new MouseEvent(ev, { bubbles: true }));
  wrap.dispatchEvent(new MouseEvent(ev, { bubbles: true }));
  box.dispatchEvent(new MouseEvent(ev, { bubbles: true }));
});

// ② 等 ≥650ms（面板有展开动画）

// ③ 在可见面板里按文本匹配后点击
```

**判断面板可见性**：
```js
var dd = null;
document.querySelectorAll('.el-select-dropdown').forEach(function (d) {
  if (d.offsetParent !== null && d.querySelectorAll('.el-select-dropdown__item').length) dd = d;
});
```

> ⚠️ **致命陷阱**：页面上所有 el-select 的 dropdown 都会**预先渲染在 DOM 里**，只有打开的那个 `offsetParent !== null`。
> **绝对不要用"最后一个可见面板"做兜底**——本次实测就是把**手机号区号下拉**误当成了「国家/地区」下拉（前者的选项是"中国 +86 / 中国香港 +852…"，后者是"中国 / 中国香港 / 中国澳门 / 中国台湾 / 美国…"），导致选择一直"未匹配"。

### 4.4 级联 el-cascader —— 逐级点

DOM 结构：
```html
<div class="el-cascader">
  <div class="el-input el-input--suffix">
    <input type="text" placeholder="请选择目前就读地" class="el-input__inner">  <!-- 注意：非 readonly -->
  </div>
</div>
```

**层级实测**：`中国大陆 → 上海 → 上海市`（三级；点省份时如果该省是直辖市，第三级只有"上海市"一个节点）

**步骤**：
1. 点 input 打开面板（同样派发 mousedown/mouseup/click）
2. 逐级点节点，每级间隔 ≥600ms：
```js
var p = null;
document.querySelectorAll('.el-cascader-panel').forEach(function (x) {
  if (x.offsetParent !== null) p = x;
});
var menus = p.querySelectorAll('.el-cascader-menu');
var nodes = menus[menuIndex].querySelectorAll('.el-cascader-node');
for (var i = 0; i < nodes.length; i++) {
  if (nodes[i].innerText.trim() === label) {
    ['mousedown', 'mouseup'].forEach(function (ev) {
      nodes[i].dispatchEvent(new MouseEvent(ev, { bubbles: true }));
    });
    nodes[i].click();
    break;
  }
}
```

节点结构：
```html
<li role="menuitem" class="el-cascader-node" aria-haspopup="true">
  <span class="el-cascader-node__label">中国大陆</span>
  <i class="el-icon-arrow-right el-cascader-node__postfix"></i>
</li>
```

**回读**：值形如 `中国大陆 / 上海 / 上海市`。

### 4.5 日期 el-date-editor —— 可直接赋值

它的 input **不是 readonly**，所以可以用 value setter（这类控件走的是原生 input 事件）：

```js
var el = document.querySelectorAll('input[placeholder="选择日期"]')[idx];
var proto = Object.getPrototypeOf(el);
Object.getOwnPropertyDescriptor(proto, 'value').set.call(el, '2023-09-01');
el.dispatchEvent(new Event('input', { bubbles: true }));
el.dispatchEvent(new Event('change', { bubbles: true }));
el.dispatchEvent(new KeyboardEvent('keydown', { key: 'Enter', keyCode: 13, bubbles: true }));
el.dispatchEvent(new Event('blur', { bubbles: true }));
```

> ⚠️ 同一页有多种日期 placeholder：「选择日期」（教育/实习/项目起止）和「请选择获奖时间」（获奖时间）。
> ⚠️ 「获奖时间」控件回读只显示到年（如 `2025`），不是填写失败。

## 五、简历附件自动上传（一开头就有的信息）

### 5.1 上传命令

```bash
curl -s -X POST "http://localhost:3456/setFiles?target=<TARGET_ID>" \
  -d '{"selector":"input[type=file]","files":["/绝对路径/03-营销策划-余生姜-演示.pdf"]}'
```

返回：`{"success":true,"files":1}`

**原理**：CDP 的 `DOM.setFileInputFiles` 直接设置 file input 的文件列表，**绕过系统文件对话框**，也不需要 `clickAt` 触发对话框。文件控件即使 `display:none` 也能生效。

**为什么 `selector` 用 `input[type=file]` 就够**：它会命中 DOM 顺序第 0 个，正好是简历附件。

### 5.2 上传后会发生什么（重点）

Chrome 自动派发 change 事件 → 页面上传 → **腾讯自动解析简历并填充表单**。

页面出现提示：
> 解析简历内容已填写到下方表单，如有问题，可补充和编辑修改

**实测解析结果（约 8–13 秒完成）**：

| 项 | 数量 |
|---|---|
| 自动填入字段 | **22 项** |
| 自动新增的经历块 | 第二个项目块（`AI职业实操系列`）|
| 效果 | **控件序号整体漂移**，之前按索引定位的做法全部失效 |

自动解析填入的内容（实测）：
- 姓名、邮箱、学历、学校名称、专业
- 教育起止（日期被解析成月初，如 `2027-06-01`）
- 实习公司、职位、起止
- 项目 1（课程与实战营发售）、项目 2（AI职业实操系列）
- 实习描述、项目描述、项目 2 描述
- 补充信息（被填入了"专业技能"内容）

**结论**：解析只覆盖了**经历类**字段。基础信息（性别、国家/地区、手机、当前所处地、微信、QQ、紧急联系人）、意向信息（期望城市、事业群、部门、面试城市）、教育细节（就读地、院系、成绩排名、GPA）、获奖、AI 技能、作品与主页、证明人 —— **全部需要脚本补齐**。

## 六、定位策略：为什么不能用索引

### 问题
最初按 `document.querySelectorAll('input')[n]` 的序号定位。**上传简历触发自动解析后，页面动态新增了经历块，索引全部漂移**（实测同一字段的索引偏移了 +1 到 +6 不等）。

### 解决：按标签定位

页面上每个字段都有 `<div class="subtitle">字段名<span>*</span></div>`。

```js
function boxOf(labelPrefix, nth) {
  var hits = [];
  document.querySelectorAll('.subtitle').forEach(function (s) {
    var t = s.innerText.replace(/\s+/g, '');
    if (t.indexOf(labelPrefix) !== 0) return;
    var p = s.parentElement;
    for (var k = 0; k < 4 && p; k++) {
      if (p.querySelectorAll('input,textarea').length > 0) break;
      p = p.parentElement;
    }
    if (p) hits.push(p);
  });
  return hits[nth || 0] || null;
}
```

### ⚠️ 关键坑：字段容器不是 `.input_box`

`.subtitle` 的 `closest('.input_box')` **实测返回 `null`** —— subtitle 并不在 `input_box` 内部。

正确做法是：**从 `.subtitle` 向上逐层找第一个内部含 `input`/`textarea` 的祖先元素**。

这个坑之所以一度被掩盖，是因为早期探测代码写了 `s.closest('.input_box') || s.parentElement` 的兜底，看起来"能取到容器"，实际取到的是 `parentElement`。**教训：兜底逻辑会掩盖错误，探测代码不要写兜底。**

### 同名多字段用 nth 区分
- `起止时间` 有 4 组：nth 0=教育、1=实习、2=项目1、3=项目2
- `描述` 有 4 组：nth 0=实习、1=项目1、2=项目2
- `项目名称` 有 2 组
- `GPA-GPA` 和 `GPA-BASE` 前缀即可区分

## 八、踩过的坑汇总（按严重程度）

### 坑 1：DOM 赋值填文本框，值会被回滚 🔴
- 现象：`el.value = x` + dispatchEvent(input) 后能读到值，但做几轮其他交互后全部被清空
- 原因：Element Plus 受控组件，Vue 数据层没更新，重渲染时用旧数据覆盖 DOM
- 修复：改用 `document.execCommand('insertText')`

### 坑 2：用"最后一个可见下拉面板"做兜底，取错控件 🔴
- 现象：「国家/地区」选择一直"未匹配"，日志显示候选前 5 项是"中国/中国香港/中国澳门/中国台湾/美国"，而代码匹配的是"中国 +86"
- 原因：`visibleDropdown()` 取到了手机号区号下拉（`my-selent-phone`）
- 修复：不要兜底；**先确认点击的那个 el-select 确实展开了自己的面板**，再做匹配

### 坑 3：索引定位在页面动态变化后失效 🔴
- 现象：上传简历自动解析后，同一字段的 input 索引偏移 +1~+6
- 修复：改用 `.subtitle` 标签定位

### 坑 4：用 `.input_box` 找字段容器，返回 null 🟡
- 现象：脚本 52 步里几乎全部报"无输入框"
- 原因：`.subtitle` 不在 `.input_box` 内部；早期探测的 `|| parentElement` 兜底掩盖了这个事实
- 修复：从 `.subtitle` 向上找第一个含控件的祖先

### 坑 5：日期 placeholder 不止一种 🟡
- 「选择日期」×多 + 「请选择获奖时间」×1
- 修复：获奖时间单独用 placeholder 定位

### 坑 6：长表单操作过快导致前一步被打断 🟡
- 修复：串行队列，每步间隔 650–800ms，并在操作前 `scrollIntoView({block:'center'})`
- 附带好处：录屏时用户能看清每个字段被填写的过程

### 坑 7：Chrome 远程调试开关找不到 🟢
- 现象：用户反馈"没看着开关在哪里"
- 原因：开关是 `chrome://inspect` 页面正文里的复选框，不在浏览器设置
- 修复：`open` 命令直接打开该页 + osascript 切到前台 + 生成位置示意图
